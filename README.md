# 循环探险 · Loop Adventure

一个跑在单个 HTML 文件里的 HTML5 Canvas 肉鸽平台游戏：无限循环的地图、打怪清圈，
每圈结束一次"圆桌投票"决定下一圈是赏是罚，偶尔还有个副本和一个龙 Boss。

**直接玩**：[`循环探险5.html`](循环探险5.html) —— 双击用浏览器打开即可，不依赖任何外部文件、不需要服务器。

## 玩法

| 操作 | 说明 |
|---|---|
| ← → | 移动（触屏上是左右两个圆钮） |
| 跳跃 | 落地后可以无限跳；空中额外两次滞空跳 |
| 冲刺 | 拿到剑之后解锁，冲刺期间无敌 |
| 开火 | 拿到火焰之后解锁 |
| 🔇 / 按 `M` | 静音开关（会记住选择） |

- **清圈**：把这一圈刷出来的怪全部打掉，进入下一圈，怪变多也变强。
- **圆桌投票**：每清完一圈，屏幕中央 5 位"村民"逐个亮出 ✅/❌，
  投票结果决定下一圈是放行（回血）还是加码（多刷一只怪）。
  第 3 位村民是"隐狼"，只有本圈拿到过火焰才会在亮票后露出红眼。
- **副本**：地图上有个隐藏入口，进去要打 8 只怪，清空有 +300 分奖励。
- **Boss**：每 3 圈出现一次。

## 目录

```
循环探险5.html      ← 可玩的单文件(仓库根目录), 由 src/ 构建出来的产物
src/                ← 开发用的拆分源码
  单文件版.html     ← 开发结构: 引擎代码 + 用 <script src> 引各类库
  physics.js        ← Ent 物理基类(AABB 碰撞/落地判定)
  player.js         ← Player 玩家
  enemy.js          ← Enemy 怪物的外观与物理(行为交给 ai.js)
  ai.js             ← 怪物行为表(状态机表驱动)
  dragon.js         ← Dragon Boss
  item.js / box.js  ← 道具 / 箱子
  audio.js          ← Web Audio 合成器(纯代码合成, 不带音频文件)
  council-ui.js     ← 圆桌投票头像动画
  boot.js           ← 启动入口
  build.js          ← 把 src/ 内联成根目录的单文件
  README.md         ← 类库说明(加载顺序 / 怎么加新怪型 / 音效接口)
```

## 构建

```bash
cd src
node build.js          # -> ../循环探险5.html
```

不需要 `npm install`，没有第三方依赖。

## 一些实现上的细节

- **怪物 AI 是表驱动的**：`ai.js` 里每个状态用 `registerBehavior()` 注册一段
  "这一帧做什么、返回下一个状态"的函数，`runBrain()` 每帧调用一次。
  加一种新怪只要注册一个状态，引擎和 `Enemy` 类都不用改。
- **音效是实时合成的**，没有任何音频文件。合成器用的是自己带种子的伪随机噪声——
  它**不能**调用全局 `Math.random`，否则会把怪物 AI 的随机序列整条推歪。
- **确定性**：同一个随机种子下，改动前后跑 900 帧逐帧一致，用来做回归测试。
